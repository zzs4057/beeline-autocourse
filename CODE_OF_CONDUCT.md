# Code of Conduct

## Expected behavior

- Be respectful and constructive.
- Discuss technical issues using reproducible evidence.
- Sanitize screenshots, logs, and network data before sharing.
- Respect platform terms, copyrights, and local law.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing another person's credentials or private data.
- Requesting or contributing risk-control bypasses, fake progress, or unauthorized API access.
- Encouraging illegal use of the project.

## Enforcement

The repository owner may edit, close, or remove contributions that violate these rules.
