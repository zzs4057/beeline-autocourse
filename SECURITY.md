# Security Policy

## Supported versions

Security and privacy fixes are applied to the latest release.

## Reporting

Do not open a public issue containing:

- Account credentials;
- Cookies or authorization tokens;
- Personal course information;
- Unsanitized HAR files;
- Signed video URLs.

Report vulnerabilities through a private GitHub security advisory when available, or contact the repository owner privately.

## Scope

The userscript performs local DOM operations and browser storage only. It does not call platform completion APIs or transmit learning data to third-party services.

Reports about bypassing platform risk controls are out of scope. The project will not implement visibility spoofing, progress fabrication, or anti-cheat evasion.
